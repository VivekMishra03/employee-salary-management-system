## What this does and does not show
- It shows the seed completes, at the specified volume, in about half a minute over a long network path.
  The earlier run on the first dataset reported employee count 10,001, one more than the seed makes; that
  extra row was a record created through the UI and was removed by this run's wipe.
- It does not show repeatability by a second run. Repeatability of the generated data is asserted by
  committed tests at 300 employees and was compared by hand across processes at 10,000 (ADR-0014).
- No second, independent run was made, so this is one observation and not a distribution.
